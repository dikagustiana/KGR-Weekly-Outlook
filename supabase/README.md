# Supabase

- `migrations/` — schema (PRD §4), RLS per role, audit trail, upload RPC, login allow-list. Apply in order (`supabase db push` or the SQL editor).
- `seed/` — generated by `npx tsx scripts/seed-sql.ts <weekStart> [adminEmail]` from `fixtures/week-<weekStart>/`: master data (I_Master, I_Item, I_COA) and the example week 24–30 Aug 2026. For local development (`supabase db reset`). In production the example week is loaded from the app (Admin → Minggu → "Muat minggu contoh"), which goes through the same RLS-protected path as any upload.
- First admin: `insert into public.app_user (email, role) values ('<email>', 'admin');` (if not there yet), then in the SQL editor `select public.set_login_password('<email>', '<strong password>');`. Self sign-up is refused (`20261014000600_signup_lock.sql`); every later login is created by the Admin in the app (Admin → Pengguna).
- `tests/rls_roles.sql` — role test (PRD §10) that impersonates test users and always rolls back; results come back in the final error message.
