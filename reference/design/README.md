# reference/design

Berkas di folder ini adalah spec (PRD v4 §2 prinsip 8, §5.5), setara dengan pasal PRD. Perbedaan antara mockup dan teks diselesaikan dengan bertanya.

Isi sekarang: `tokens.css` (§5.2, disalin dari teks PRD).

Mockup `minggu-ini.html`, `outlook-bulan.html`, `kas-solvabilitas.html`, dan `ppic-rencana.html` dibuat di irisan 1 sebelum kode halaman (§5.5) dan ditambahkan ke folder ini oleh PR irisan itu.

Belum ada di repo dan tidak ikut dikirim bersama PRD v4 (16 Okt 2026):

- `samb-bi-*.png`, screenshot samb-bi halaman Kinerja, Outlook, Ringkasan.
- `samb-bi/samb_bi/web/styles.css`, sumber token. `tokens.css` di sini diambil dari blok CSS di PRD §5.2, bukan dari berkas itu.
- `archive/`: mockup lama "KGR Management View v2" (Claude Design) yang dibongkar ke HTML.

Sampai berkas itu ditambahkan pemilik produk, grammar samb-bi hanya dibaca dari teks PRD §5.3 dan §6. Dicatat di `docs/v4/QUESTIONS.md` Q3.
