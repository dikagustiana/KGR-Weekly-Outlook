## 7. Cara memakai (Kepala Sales atau Admin)

1. Komersial → kartu "Approval diskon menunggu" → "Penugasan Sales" (Admin: juga Admin → Pengguna). Alamat langsung: `/komersial/assignment`.
2. Pilih Sales, isi key: **key dasar** (`RPA|Karkas`) bila Sales itu membuat komitmen minggu depan atau perlu semua bentuk; **key dengan bentuk** (`RPA|Karkas|Fresh`) hanya untuk satu bentuk. Pelanggan kosong = semua pelanggan; bila diisi, samakan dengan nama di PO.
3. Simpan. Sales melihatnya pada muat ulang berikutnya di Komersial. "Nonaktifkan" mencabut akses (baris tetap ada); "Ubah" mengganti key, pelanggan atau catatan.
4. Ringkasan di atas halaman memperlihatkan apa yang dicakup tiap Sales; Sales tanpa penugasan aktif tidak melihat SKU apa pun.

## 8. Cara mengulang

```bash
pnpm install                                   # lokal tanpa cdn.sheetjs.com: override sementara "@kgr/parsers>xlsx": "0.18.5", jangan di-commit
pnpm typecheck && pnpm test && pnpm parity && pnpm snapshot:diff
E2E_STRICT_XFAIL=1 pnpm e2e                    # matriks (termasuk halaman penugasan), T7, A6, A7, F19, volume
E2E_ONLY="T7 A7" pnpm e2e                      # hanya A7 (di atas database T7)
# bila stack e2e worktree lain berjalan di port bawaan, beri port sendiri: E2E_PG_PORT, E2E_PGRST_PORT, E2E_SUPA_PORT, E2E_APP_PORT
```
